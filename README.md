A make.fun entry for the [Funniest Cat Voicemail Greeting](https://make.fun/competitions/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty: one line, the funniest voicemail greeting a cat would record.

The entry:

> You've reached Miso. Your call matters to me, so I knocked your phone off the table. Leave a message.

The line was picked by a candidate tournament scored on specificity, surprise and freshness. It is a voicemail trope turned by cat logic: your call matters to the cat, so the cat knocked your phone off the table.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`.

```sh
python3 main.py                  # write the entry
python3 main.py --check          # validate against the 1-120 char gate
python3 main.py --self-test      # write twice, compare bytes
python3 main.py --tournament     # print the candidate table
```
